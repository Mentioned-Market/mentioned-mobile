# Mentioned Mobile

Mentioned for the Solana Seeker: a React Native (Expo dev client) Android app
for the CLOCK IN hackathon. v0 is read-only against production. See
`docs/V0_GUIDE.md` for the v0 build order and `docs/SPEC.md` for everything
after v0.

## Run on a Seeker

Prerequisites (guide section 1): Node 20, JDK 17, Android Studio with SDK
Platform 34+, `ANDROID_HOME` set, `platform-tools` on `PATH`, USB debugging on
the Seeker and `adb devices` listing it.

```bash
npm install
npx expo run:android --device   # pick the Seeker
```

Metro serves JS over USB. The API is production, so nothing else runs locally.
Rebuild only when native dependencies change; everything else is fast refresh.

The `android/` directory is generated by `npx expo prebuild --platform android`
and is committed so builds are reproducible. Keystores are never committed.

## Layout

- `index.js` installs the crypto polyfill, then hands off to expo-router.
- `polyfill.js` runs `react-native-quick-crypto` before any Solana import.
- `src/app/` expo-router screens.
- `src/config.ts` static config: API base, RPC, program ids. No `.env`.
- `src/lib/` ported SDKs and helpers.

## PORTED_FROM rule

Any file ported from the web repo starts with a `// PORTED_FROM: <path>` comment
naming the source file, and the port table in `docs/V0_GUIDE.md` section 5 lists
every edit made to it. Nothing else in a ported file changes.

## Versions

`@solana/kit` is pinned to 7.x because
`@solana-mobile/mobile-wallet-adapter-protocol-kit` peers on `^7.0.0`. Pin every
Solana package to an exact version after the first green device build.
